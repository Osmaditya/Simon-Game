# 🧠 Simon Game - Memory Challenge in JavaScript

Simon Game is a fun and interactive memory-based game built using **HTML**, **CSS**, and **JavaScript**. It challenges users to memorize and repeat an ever-growing sequence of colors.

---
## 🎮 How to Play

1. **Press any key** to start the game.
2. Watch the **sequence of flashes** generated by the computer.
3. **Repeat the exact sequence** by clicking the colored buttons.
4. With each correct round, the **sequence length increases** by one.
5. Make a mistake? The game ends and shows your score.
6. Press any key to **restart** the game.

---

## 🚀 Features

- Colorful button animations
- Dynamic level updates
- Game over alert and restart prompt
- Built with pure vanilla JavaScript (no libraries!)

---

## 🛠️ Tech Stack

- **HTML5** – Markup
- **CSS3** – Styling and button effects
- **JavaScript** – Game logic, event handling, and user interaction
